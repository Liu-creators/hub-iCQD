需求澄清已完成。以下为**需求澄清基线纪要**，不再追问；后续如有变化，按变更记录处理。

## 一、产品定位与用户

- **产品形态**：独立 Web 产品，内部单租户，PC Web。
- **登录方式**：账号密码登录。
- **目标用户**：业务运营、管理层。
- **数据权限**：两类用户看同一套数据、同权限；一期不做行级权限。
- **核心场景**：趋势分析、同比环比、排名、对比、异常检测、归因分析。

## 二、MVP 功能边界

**MVP 必须包含：**

1. 多轮对话
2. 智能追问
3. 图表生成
4. 数据解读
5. SQL 生成、校验与自动执行
6. 异常检测与归因分析（自动执行，但归因限定为维度贡献拆解）

**一期不做、二期预留：**

- 便捷分享：一期只预留设计，二期实现。
- 输入联想、猜你想问：二期做，一期只预留接口和交互位置。
- 收藏、导出、移动端：二期。
- 表格、明细列表、导出：一期不支持；排名/TOP N 用柱状图表达。
- 管理层 KPI 总览卡片：一期不需要。
- 手动切换图表类型：一期不支持，系统自动选型。

**“结论分析”与“数据解读”合并：** MVP 只保留“数据解读”，不单独做行动建议型结论分析。

## 三、对话与追问策略

- **上下文范围**：当前会话保留最近 10 轮完整上下文，更早轮次摘要保留。
- **新话题识别**：检测到新话题时提示并自动新开会话，不静默清空。
- **指代消解**：MVP 支持“那上个月呢”“按地区拆一下”“为什么涨了”等指代。
- **智能追问触发**：只在用户问题不明确时触发，不因结果异常或固定推荐触发。
- **追问形式**：自然语言反问，一次只问 1 个澄清问题，不阻断用户继续问。
- **追问上限**：最多连续追问 2 次；用户不回答可直接继续提问。

## 四、数据与 SQL

- **数据源**：MySQL，只读账号。
- **默认数据规模假设**：表数量 ≤50；单表 ≤千万级。
- **数据字典**：暂无完整数据字典，一期由产品内置推断，包括表结构推断、字段/同义词/口径推断。
- **SQL 校验范围**：MVP 只做语法校验、表/字段存在性校验。
- **执行方式**：生成 SQL 后自动执行。
- **失败兜底**：SQL 执行失败或空结果，自动重试修正 1 次；仍失败则提示“无法生成可靠查询”，不向用户展示 SQL。
- **安全底线**：只读账号、禁止 DDL/DML、查询超时 30 秒、返回行数上限 1000、防注入。
- **SQL 准确率目标**：准备 100 条标准问题并人工标注正确 SQL，离线评测准确率 ≥90%。
- **评测口径**：单问级判定；覆盖趋势、同环比、排名、对比、异常、归因；自动重试后正确算对；不含“智能追问是否触发”的评测。

## 五、图表、异常检测与数据解读

- **图表类型**：折线图、柱状图、堆叠柱状图、饼图。
- **图表选型**：系统自动选型，用户不可手动切换。
- **异常检测**：自动按同比/环比/滚动阈值标记异常点；具体阈值待定。
- **归因分析**：自动对当前可用维度做贡献度拆解，输出“主要贡献维度 + 数值”；不解释外部原因、不编造；无法归因时明确提示“未发现显著维度”。
- **数据解读**：每个图表自动生成 3–5 条解读；只基于图表内数据，引用具体数值，不给行动建议；允许“可能受某维度变化影响”等推测，但必须标注为推测。

## 六、分享二期默认设计

一期只预留设计，二期实现。二期默认：

- 仅内部登录用户可访问；
- 水印包含用户名 + 时间；
- 有效期默认 7 天，可修改；
- 访问权限按角色/部门控制；
- 禁止分享 SQL 和明细，只分享图表 + 解读 + 筛选条件。

## 七、部署、模型与一期范围

- 内部单租户；
- 允许调用公有云大模型，但数据需脱敏后发送；
- 账号密码登录；
- 一期包含 PC Web、会话历史、审计日志；
- 收藏/导出/移动端二期；
- 接受默认假设：表 ≤50、单表千万级、管理层与运营同数据同权限、一期不做行级权限。

## 八、成功指标

1. **提问到图表成功率**：主口径为“返回非空图表且无系统错误”算成功；是否排除用户点“结果不对”的样本，待定。
2. **SQL 准确率**：100 条标准问题离线评测，单问级判定，自动重试后正确算对，目标 ≥90%。

## 九、待定项与风险

1. 一期无完整数据字典，依赖产品内置推断，**90% SQL 准确率存在达成风险**；需通过 100 条标注集验证，必要时补轻量语义层或调整阈值。
2. 脱敏规则未定：需明确脱敏字段、规则、是否可逆。
3. 异常检测阈值具体值未定：同比/环比/滚动窗口阈值需配置。
4. 图表自动选型规则未定。
5. 新话题识别阈值与策略未定。
6. 审计日志字段、保留期、会话历史保留期未定。
7. SQL 准确率评测集由谁提供、标注规范未定。
8. “提问到图表成功率”是否排除“结果不对”样本未定。
9. 公有云大模型供应商与合规评审未定。
10. 归因效果依赖可用维度；维度不足时归因能力受限。
11. 一期不支持表格/明细/导出，可能影响运营“列出明细”类问题，需在范围说明和话术中明确。
