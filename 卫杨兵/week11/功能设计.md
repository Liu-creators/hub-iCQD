下面给出 **ChatBI 产品功能设计 V0.1（一期 MVP 可落地版）**。按“页面结构 → 功能模块 → 核心流程 → 状态与兜底 → 优先级与验收 → 二期预留”组织，可直接作为后续 PRD 和原型设计的目录。

---

## 一、设计目标与原则

1. **非专业用户可用**：用户用自然语言提问，系统自动完成理解、追问、查询、图表和解读。
2. **自动优先**：自动选图、自动异常检测、自动归因、自动生成解读；一期不提供手动切换图表。
3. **不展示 SQL**：SQL 只在系统内部生成、校验、执行；失败时给用户可理解提示。
4. **不编造**：数据解读只基于图表内数据并引用数值；推测必须标注“推测”；无法归因时明确提示。
5. **边界清晰**：一期不做表格/明细/导出/分享/联想/猜你想问，但预留接口和交互位置。
6. **可追溯**：会话历史、审计日志、查询状态可追踪，支撑成功率和 SQL 准确率验收。

## 二、信息架构与页面结构

### 1. 登录页
- 账号密码登录。
- 内部单租户，不接 SSO。
- 登录后进入主对话工作台。

### 2. 主对话工作台（PC Web）
建议三栏布局：

- **左侧：会话列表**
  - 新建会话、历史会话、会话重命名、删除、按时间排序。
  - 当前会话高亮。
- **中间：对话流**
  - 用户消息、助手回复、澄清追问、图表卡片、解读卡片、异常/归因卡片、失败提示。
  - 底部输入框：一期无输入联想；预留联想/猜你想问容器位置，UI 不展示。
- **右侧：可选上下文面板**
  - 显示当前会话继承的指标、时间、筛选、维度等上下文，便于用户理解“系统记住了什么”。
  - 一期可作为轻量信息展示，不做复杂编辑。

### 3. 管理后台（内部管理员）
- **数据源与语义配置**：MySQL 连接、只读账号、表范围、字段可见性、同义词/指标口径补充、脱敏字段配置。
- **异常检测配置**：同比/环比/滚动窗口阈值配置。
- **审计日志**：按用户、时间、会话 ID、查询状态检索。
- 一期不做复杂权限管理，管理员与普通用户区分即可。

### 4. 二期预留页面/位置
- 图表卡片工具栏预留“分享”位置，一期隐藏。
- 输入框上方预留“输入联想/猜你想问”容器，一期隐藏。
- 分享访问页二期设计，一期不实现。

## 三、功能模块设计

### F1 登录与权限
- 账号密码登录；内部单租户。
- 业务运营和管理层同数据、同权限；一期不做行级权限。
- 未登录不可访问会话和图表。
- 管理员可进入管理后台；普通用户不可见后台入口。

### F2 会话管理
- 新建会话、历史会话列表、重命名、删除。
- 会话内保留最近 10 轮完整上下文，更早轮次摘要保留。
- 检测到新话题时：提示“检测到新话题，已新建会话，原会话保留”，自动新开会话，不静默清空。
- 用户可返回原会话继续查看。
- 一期不做收藏；收藏二期。

### F3 对话输入与消息流
- 用户输入自然语言问题并发送。
- 消息状态：理解中 → 查询中 → 生成中 → 完成/失败/追问中。
- 助手消息支持：澄清追问、图表卡片、数据解读、异常标记、归因结果、失败提示。
- 一期输入框不展示联想词和猜你想问；仅预留接口和容器。

### F4 意图理解、指代消解与智能追问
- 支持趋势、同比环比、排名、对比、异常检测、归因分析等意图。
- 支持多轮指代：如“那上个月呢”“按地区拆一下”“为什么涨了”。
- 继承当前会话上下文：指标、时间范围、筛选条件、维度、图表类型、前轮结论等。
- 智能追问规则：
  - 仅在用户问题不明确时触发；
  - 自然语言反问；
  - 一次只问 1 个澄清问题；
  - 不阻断用户继续提问；
  - 最多连续追问 2 次；用户不回答可直接继续问。
- 追问示例：“你说的‘销售额’是指订单金额还是支付金额？请确认口径。”

### F5 SQL 生成、校验与自动执行
- 系统内部生成 SQL，用户界面不展示 SQL。
- 校验范围：语法校验、表/字段存在性校验。
- 自动执行；失败或空结果时自动重试修正 1 次。
- 仍失败则提示：“无法生成可靠查询，请补充指标/时间/维度或换个问法。”
- 空结果重试后仍空：提示“未查询到数据，请确认筛选条件。”
- 工程底线：只读账号、禁止 DDL/DML、超时 30 秒、返回行数上限 1000、防注入。
- 执行过程对用户展示简化状态，不暴露 SQL 和表结构细节。

### F6 图表生成
- 支持图表：折线图、柱状图、堆叠柱状图、饼图。
- 系统自动选型，用户不可手动切换。
- 建议选型规则：
  - 时间趋势 → 折线图；
  - 分类对比、排名/TOP N → 柱状图；
  - 时间 + 多系列构成 → 堆叠柱状图；
  - 占比/构成 → 饼图。
- 排名/TOP N 用柱状图表达；一期不支持表格、明细列表、导出。
- 图表卡片展示：标题、图表、时间/筛选条件摘要、数据更新时间（如可获得）、解读入口区域。
- “提问到图表成功”口径：返回非空图表且无系统错误。

### F7 数据解读
- 每个图表自动生成 3–5 条解读，不需要用户点击触发。
- 只基于图表内数据，引用具体数值。
- 不给行动建议；不解释外部原因。
- 允许“可能受某维度变化影响”等推测，但必须标注“推测：”。
- 示例：
  - “销售额在 6 月达到峰值 1,230 万，环比增长 18%。”
  - “推测：增长主要来自华东区域，贡献约 42%。”

### F8 异常检测与归因分析
- 自动按同比/环比/滚动阈值标记异常点。
- 图表上标记异常点；解读中说明异常。
- 归因：自动对当前可用维度做贡献度拆解，输出“主要贡献维度 + 数值”。
- 不解释外部原因、不编造；无法归因时提示“未发现显著维度”。
- 归因结果以卡片或展开区呈现，例如“主要贡献维度：华东区域，贡献 42%；渠道 A，贡献 21%。”
- 阈值在管理后台配置；一期默认值待定。

### F9 会话历史与审计日志
- 会话历史：列表、查看、重命名、删除；保留期待定。
- 审计日志最小字段建议：用户、时间、会话 ID、问题摘要、查询状态、错误码、耗时、是否触发追问、是否异常/归因、是否失败重试。
- 用户界面不展示 SQL；后台审计是否存 SQL 需合规确认，列为待定。
- 审计日志一期支持检索查看，导出二期。

### F10 数据源与语义配置
- 管理员配置 MySQL 连接、只读账号、表范围、字段可见性。
- 因一期无完整数据字典，系统从表结构自动推断字段、同义词、口径；管理员可补充指标定义、维度、时间字段、同义词、示例问题。
- 脱敏字段和脱敏规则配置；调用公有云大模型前按规则脱敏。
- 该模块是 90% SQL 准确率的关键支撑，建议一期必须保留轻量配置能力。

### F11 二期预留接口与位置
- 分享：图表卡片工具栏预留位置，一期隐藏；二期实现仅内部登录访问、水印=用户名+时间、有效期默认 7 天可改、按角色/部门权限、禁止分享 SQL 和明细。
- 输入联想、猜你想问：输入框上方预留容器和接口，一期不展示。
- 收藏、导出、移动端：二期。

## 四、核心用户流程

1. 用户登录 → 进入工作台。
2. 新建会话或打开历史会话。
3. 输入问题，如“看一下最近半年销售额趋势”。
4. 系统判断是否明确：
   - 不明确 → 自然语言追问 1 个问题，不阻断；
   - 明确 → 生成 SQL。
5. SQL 语法/表字段校验 → 自动执行。
6. 失败或空结果 → 自动重试修正 1 次 → 仍失败给提示。
7. 成功 → 自动选图 → 渲染图表。
8. 自动异常检测 → 标记异常点。
9. 自动归因 → 输出维度贡献拆解或“未发现显著维度”。
10. 自动生成 3–5 条数据解读。
11. 用户继续多轮追问；系统继承上下文；检测新话题则提示并新开会话。
12. 会话与审计日志记录。

## 五、关键状态与兜底话术

| 场景 | 产品表现 |
|---|---|
| 问题不明确 | 自然语言反问 1 个问题，可继续输入 |
| SQL 校验失败 | 内部自动修正重试 1 次，不展示 SQL |
| 执行失败/空结果 | 重试 1 次；仍失败提示“无法生成可靠查询……”或“未查询到数据……” |
| 图表为空 | 不算成功；给失败提示 |
| 无法归因 | 明确提示“未发现显著维度” |
| 新话题 | 提示并自动新开会话，原会话保留 |
| 用户点“结果不对” | 一期可记录反馈埋点；是否排除成功率样本待定 |

## 六、优先级与验收

**P0 一期必须：** 登录、会话管理、对话流、智能追问、指代消解、SQL 生成校验执行、四类图表自动选型、数据解读、异常检测、归因、审计日志、数据源与语义配置。

**P1 一期增强：** 新话题提示、上下文摘要、右侧上下文面板。

**P2 二期：** 分享、输入联想、猜你想问、收藏、导出、移动端、表格/明细。

**验收指标：**
- 提问到图表成功率：返回非空图表且无系统错误算成功。
- SQL 准确率：100 条标准问题离线评测，单问级判定，覆盖趋势/同环比/排名/对比/异常/归因，自动重试后正确算对，目标 ≥90%。
- 埋点需覆盖：提问、追问触发/回答、SQL 校验失败、执行失败/空结果、重试、图表类型、解读生成、异常标记、归因展开、新话题提示、会话新建。

---

## 七、主要待定项

1. 异常检测同比/环比/滚动阈值默认值。
2. 图表自动选型规则的具体边界和 TOP N 默认值。
3. 脱敏字段、规则、是否可逆。
4. 审计日志是否存 SQL、保留期、字段合规确认。
5. SQL 准确率评测集提供方与标注规范。
6. 提问到图表成功率是否排除“结果不对”样本。
7. 公有云大模型供应商与合规评审。
8. 数据源与语义配置的具体字段和操作粒度。
