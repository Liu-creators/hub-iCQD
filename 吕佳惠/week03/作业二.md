=====================
运行 main.py，读取 config.py 获取全局配置
通过生命周期事件，提前加载：
model/bert.py：加载 BERT 逻辑
model/prompt.py:加载大模型逻辑
model/regex_rule.py：加载正则规则
model/tfidf_ml.py: tfidf逻辑

单次 HTTP 请求完整链路
客户端发起 POST 请求到达main.py中定义的接口路由
参数不合法 → 直接返回错误日志 + 报错 JSON
参数校验通过，进入业务逻辑
封装标准返回 JSON，发送给客户端
