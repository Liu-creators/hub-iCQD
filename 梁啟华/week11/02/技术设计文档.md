3.1 总体架构
推荐分层架构，核心链路为：

text
用户界面（对话 + 过程可视化）
        ↓
API 网关 / 会话服务
        ↓
Agent 编排层（ReAct 循环 · 工具路由 · 失败回退）
        ↓
意图解析 → Schema Linking → SQL 生成/校验 → 安全护栏 → 执行引擎
        ↓
语义层（指标字典 · 同义词 · 业务术语向量库）
        ↓
数据源（数仓 / OLAP / 业务库）
Agent 编排建议采用 LangGraph 或等价的状态机框架，将“理解—检索—生成—校验—执行—解读”建模为可观测节点，每个节点输出契约化事件，便于前端展示和事后回放。V2 阶段的核心技术决策是：LLM 参与路由决策，规则作为降级路径，而不是让规则引擎做唯一决策者。

3.2 Text-to-SQL 技术路径与关键决策
三条路径的取舍需要在技术设计文档中显式记录：

路径	适用阶段	关键约束
直接 NL→SQL	单表/简单聚合的 PoC	Schema 精简时可用，复杂跨表易产生慢查询和幻觉
NL→语义层→SQL（推荐主线）	生产级	需要语义层先行建设，但准确率和可治理性显著更优
NL→DSL→物理 SQL	强治理场景	语义层以 DSL 形式声明，可确定性渲染，适合审计要求高的环境
Schema Linking 是准确率的第一杠杆。 不要将全量 Schema 塞入 prompt；应通过向量检索召回候选表，并配合双向检索策略将召回集向“完美 Schema”逼近。对于多表 JOIN 场景，语义层中显式声明的关系和 join 键是比让模型“猜”更可靠的方式。

Prompt 工程层面，采用 Few-Shot + Chain-of-Thought 组合：先让模型识别时间范围、维度、指标和过滤条件，再确定 SELECT/FROM/WHERE/GROUP BY 结构，最后生成完整 SQL。SQL 生成后必须经过语法校验和权限注入，再进入执行层。

3.3 语义层设计
语义层是 ChatBI 区别于“LLM 直连数据库”的核心资产。建议的最小构成：

指标定义：名称、同义词、口径 SQL 片段、默认聚合方式、可用维度；

实体关系：表间 join 关系与基数，显式声明而非让模型推断；

字段安全属性：敏感级别、是否可明细下钻、脱敏规则；

业务术语映射：将用户口语（“上月”“大客户”“有效订单”）映射到语义层元素。

语义层可以以文件或元数据表形式落地，关键在于它是可版本化、可评审、可回归的制品，而不是散落在 prompt 中的隐式知识。

3.4 安全与权限架构
安全设计需要把权限校验放在靠近查询执行的位置，而不是仅依赖前端入口鉴权。核心机制：

行级/列级权限动态注入：在 SQL 进入执行引擎前，根据提问者身份向 WHERE 子句注入行级过滤条件，对无权限列进行屏蔽或拒绝；

查询继承用户身份：执行 SQL 时使用提问者映射的数据源账号，避免“服务账号高权限查询 → 结果返回低权限用户”的典型事故模式；

SQL 安全护栏：语法级校验（禁止 DDL/DML 非查询语句）、复杂度/代价预估、慢查询拦截、结果行数上限、超时熔断；

多租户隔离：会话、语义层配置、查询结果缓存、审计日志均按租户隔离，缓存键必须包含租户与权限上下文，防止跨租户缓存穿透；

全链路审计：从问题到 SQL 到结果摘要到权限决策完整留痕，满足等保/GDPR 等合规要求。

3.5 Agent 与可观测性
V2 的 Agent 骨架应包含：循环上界（防止无限 ReAct）、工具封装（Schema 检索、SQL 执行、术语查询、澄清追问）、失败分类与回退策略（检索无命中→是否允许转 SQL 需有门控）、事件契约。过程帧建议至少覆盖：step_start / thought_summary / intent_resolved / tool_call / step_end / final_answer，字段最小集在前后端之间锁定并做契约测试。

3.6 评测与持续优化
评测体系需要分两级：

离线回归：维护 golden set（问题 + 期望结果/期望 SQL 语义），覆盖核心指标和典型多表场景。BIRD 基准上当前最好系统约 82%，人类专家约 93%，可作为“距离上限还有多远”的外部参照，但内部 golden set 才是准入依据；

在线监控：查询成功率、用户“数不对”反馈率、P95 延迟、慢查询占比、澄清追问触发率、权限拒绝率。Bad Case 自动归集并进入下一轮语义层修订和 golden set 扩充，形成闭环。

关键验收指标建议：V2 阶段以“执行准确率（结果可对账）≥ 内部阈值 + 过程事件契约通过 + 失败回退覆盖 Top-5 失败类型”作为退出标准；V3 再加入 SLA、权限渗透测试通过率和多租户隔离验证。
