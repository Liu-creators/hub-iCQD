---

### 一、实验概述

#### 1.1 实验目的
探究不同 **Batch Size** 与 **Learning Rate** 组合对BERT模型微调效果的影响，为实际训练提供最优参数选择依据。

#### 1.2 实验配置

| 实验组 | Batch Size | Learning Rate | 标识 |
|--------|-----------|---------------|------|
| 组1 | 10 | 1e-2 | bs10_lr1e-2 |
| 组2 | 10 | 1e-4 | bs10_lr1e-4 |
| 组3 | 10 | 5e-5 | bs10_lr5e-5 |
| 组4 | 16 | 5e-5 | bs16_lr5e-5 |
| 组5 | 30 | 5e-5 | bs30_lr5e-5 |

#### 1.3 评估指标
- **Eval Loss**：验证集交叉熵损失，反映模型预测置信度
- **Eval Accuracy**：验证集准确率，反映模型预测正确率
- **收敛速度**：达到高准确率所需的Epoch数
- **训练稳定性**：各Epoch间指标的波动程度

### 五、深度分析与规律总结

#### 5.1 学习率的影响（固定 Batch Size=10）

| 学习率 | 最终效果 | 收敛特征 | 结论 |
|--------|---------|----------|------|
| **1e-2** | 完全失败 (12%) | 损失不降，准确率随机震荡 | 步长过大，梯度爆炸/震荡 |
| **5e-5** | 最优 (94%) | 稳定渐进，Epoch 3大幅提升 | 步长适中，平稳收敛 |
| **1e-4** | 优秀 (92%) | 快速收敛，Epoch 2达71% | 步长较大，收敛快但略过拟合 |

**关键发现**：
- 学习率存在"黄金区间"：`5e-5 ~ 1e-4`
- 过大（1e-2）：模型完全无法学习 → **灾难性失败**
- 略大（1e-4）：收敛快但出现过拟合信号（Loss降但Acc降）
- 最优（5e-5）：稳步收敛，泛化最佳

#### 5.2 批次大小的影响（固定 Learning Rate=5e-5）

| Batch Size | 最终效果 | 收敛速度 | 训练效率 | 结论 |
|------------|---------|----------|----------|------|
| **10** | 🏆 94% | 快 | 慢（885秒） | 精度最优 |
| **16** | 78% | 中 | 较快（524秒） | 精度-效率折中 |
| **30** | 36% | 极慢 | 快 | 严重欠拟合 |

**关键发现**：
- **大Batch导致收敛变慢**：同样学习率下，bs=30几乎学不动
- **小Batch泛化更好**：梯度噪声有助于跳出局部最优
- **Batch Size影响有效学习率**：bs增大需要同步提高学习率（线性缩放规则）

#### 5.3 学习率与Batch Size的联合效应

```
                   学习率
                   ↑
        1e-2  │     ❌ 崩溃    │     ❌ 崩溃    │
              │               │               │
        1e-4  │  ✅ 优秀(92%) │  ❓ 未知     │  ❓ 未知    │
              │               │               │               │
        5e-5  │  🏆 最优(94%)│  ⚡ 可用(78%)│  🐌 欠拟合(36%)│
              │               │               │               │
              └───────────────┴───────────────┴───────────────→ Batch Size
                    10              16              30
```

**核心规律**：
1. **学习率决定了能否学习**：1e-2在任何batch下都会失败
2. **Batch Size决定学习效率**：相同学习率下，小batch收敛更快更好
3. **两者需协同调整**：增大batch时应按比例提高学习率（本实验中bs=30的lr=5e-5偏低）

### 六、Loss vs Accuracy：模型选择指南

#### 6.1 关键案例分析

| 配置 | Epoch | Eval Loss | Eval Accuracy | 解读 |
|------|-------|-----------|---------------|------|
| bs10_lr1e-4 | Epoch 3→4 | **0.5169 → 0.3099** ⬇️ | **0.93 → 0.92** ⬇️ | ⚠️ 过拟合信号 |
| bs10_lr5e-5 | Epoch 3→4 | 1.112 → 0.4416 ⬇️ | 0.92 → **0.94** ⬆️ | ✅ 健康收敛 |

#### 6.2 选择准则

| 场景 | 优先指标 | 原因 |
|------|---------|------|
| 分类任务（如你的实验） | **Eval Accuracy** | 业务目标是"预测正确率" |
| 类别不均衡 | **Eval Loss** | Accuracy可能虚高，Loss反映真实拟合 |
| Early Stopping触发 | **Eval Loss** | Loss上升是过拟合的前兆信号 |
| Loss降但Acc降 | **Eval Accuracy** | 说明模型过度自信但判别力下降 |

**本次实验最优模型**：`Batch Size=10, Learning Rate=5e-5, Epoch=4`
- ✅ 准确率最高（94%）
- ✅ Loss持续下降且Acc同步提升（无过拟合信号）
- ✅ 收敛稳定，泛化能力强

### 八、最佳实践建议

#### 8.1 参数选择决策树

```
开始
  │
  ├─ 是否追求最高精度？
  │   ├─ 是 → 选择 bs=10, lr=5e-5 ✅
  │   └─ 否 ↓
  │
  ├─ 是否需要加速训练？
  │   ├─ 是 → 选择 bs=16, lr=5e-5（精度78%）
  │   └─ 否 → 继续用 bs=10
  │
  └─ 是否使用大Batch（如bs=30）？
      ├─ 是 → 必须提高学习率至 1e-4 ~ 3e-4
      └─ 否 → 保持 5e-5
```

#### 8.2 参数调整黄金法则

| 法则 | 说明 |
|------|------|
| **学习率优先** | 先确定合适的学习率区间，再调Batch Size |
| **小Batch探路** | 用bs=8~16快速探索学习率，再放大Batch |
| **线性缩放** | Batch Size翻倍，学习率大致翻倍（参考：lr_new = lr_base × sqrt(bs_new/bs_base)） |
| **早停监控Loss** | 当eval_loss连续上升，即使Acc未降也要停止 |
| **最终选型看Acc** | 对比模型时，以验证集准确率为主要KPI |

#### 8.3 本实验推荐配置

| 优先级 | Batch Size | Learning Rate | 适用场景 |
|--------|-----------|---------------|----------|
| 🥇 首选 | 10 | 5e-5 | 生产环境，追求最高精度 |
| 🥈 备选 | 16 | 5e-5 | 开发调试，需加速迭代 |
| 🥉 探索 | 30 | 1e-4 ~ 2e-4 | 需验证大Batch缩放效果 |

---

### 九、总结

#### 核心结论

1. **学习率是决定模型能否训练的关键**：1e-2过大导致完全失败；5e-5 ~ 1e-4为有效区间；5e-5在该任务中表现最优。

2. **Batch Size影响收敛质量**：相同学习率下，小Batch（10）收敛更快、精度更高；大Batch（30）收敛极慢，需配合更高的学习率。

3. **最优组合**：`Batch Size = 10, Learning Rate = 5e-5`，达到94%验证准确率，且无过拟合迹象。

4. **模型选择**：以 `Eval Accuracy` 为最终选择标准，但用 `Eval Loss` 监控过拟合风险。
