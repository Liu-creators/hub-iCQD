1：从本质上来说
    LangChain框架提供的一整套工具生命周期管理方案，langchain 工具调用是框架层编排，是完整的工具调用解决方案
    llm function call是大模型自身具备的一种结构化输出能力

    从功能上来说
    langchain 工具调用包括工具注册、Prompt 组装、模型调度、输出解析、工具执行、结果回传、多轮循环、容错、答案生成
    llm function call模型只判断是否调用工具、调用哪个工具、传入什么参数，并以约定的结构化格式返回
    
    从关系上来说
    langchain 工具调用功能可以调用llm function call功能来实现，也可以不依赖而实现，上下层关系

2：首先最主要受到大模型的速率影响，其次就是工具执行的时间，然后就是工具调用过程中参数错误，纠错，调用轮数的影响
    在复杂系统中，LangChain 框架自身的中间开销，包括 Prompt 模板渲染、上下文组装、输出解析、参数校验、记忆模块读写等封装层开销
    在复杂系统中，是否使用并发或者串行
