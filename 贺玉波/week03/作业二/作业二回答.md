客户端 HTTP POST → FastAPI → Pydantic 校验 → 路由处理函数 → 模型推理 → 返回 JSON

客户端 HTTP POST：向服务端发送请求

FastAPI → Pydantic 校验：如果客户端传了 request_text: 123（数字而不是字符串），Pydantic 会直接抛 ValidationError，FastAPI 自动返回 HTTP 422，不会进handler。只有校验通过的请求才会走到路由函数体内

路由处理函数 → 模型推理：计时，构造响应框架，日志记录，调用方法推理（Regex，TF-IDF，BERT，GPT）和异常兜底，返回响应

返回 JSON：FastAPI 序列化 TextClassifyResponse（schema存在，fastapi自动当作响应处理规则）
